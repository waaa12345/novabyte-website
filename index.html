Before You Ask

How much will my project cost?+

We quote a fixed price after discovery, not an hourly rate. You get the full number in writing before we start, and anything added later is quoted separately — never slipped into the bill.

How long does a project take?+

It depends on scope — a landing page and an ERP rollout aren't the same job. You'll get a realistic timeline with the proposal, and weekly check‑ins so you always know where things stand.

Can you work with the systems we already use?+

Usually, yes. Custom software and ERP work both start by looking at what you run today — spreadsheets included — so integrations and data migration are part of the job, not an afterthought.

What happens after launch?+

Training, every login handed over, and a hosting and maintenance plan if you want one. Support questions go to engineers who already know your system, not a generic helpdesk.

Do you work in French as well as English?+

Yes — interfaces, documentation and support are available in both, which matters for teams that run day to day in French.
